# UV-designed crate texture

The built-in image-generation tool edited the original atlas, using the original UV wireframe and Lumen shape as references. A corrective pass reduced weathering and restored all six dark core islands. The artwork is assigned directly through CrateAtlasUV, then baked UV-to-UV in Blender into a 2048×2048 image with 8px gutter bleed. No side-panel projection, no repeating texture. All solid parts share one atlas; glow excluded. Original files and live Studium model are unchanged.
