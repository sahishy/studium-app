# Lumen crate texture

Generated with the built-in image-generation tool, then projected onto each layer's four broad exterior faces and baked in live Blender through MCP into the existing 2048×2048 shared atlas. The panel was blended 18% toward clean silver-gray to soften the weathering. Core and trim use soft gradients during baking; all solid parts share one final atlas material. Glow excluded. Geometry and UV layout preserved; Idle and Opening retained. No Studium code or live asset changes.

## Image-generation prompt

Use case: stylized-concept. Asset type: flat base-color texture for a minimalist low-poly loot crate, NOT a rendered object.
Reference image: supplied Lumen icon is a shape reference only. Reproduce its rounded four-point sparkle silhouette and rounded square cutout faithfully, but recolor it gray.
Generate a single WIDE horizontal rectangular painted surface texture, aspect ratio roughly 3.5:1. Fill the entire canvas edge to edge, no background or outside margin, no perspective, no mockup, no box or 3D object, no text.
Palette: bright cool silver gray with only a VERY faint blue tint. Broad smooth noticeable vertical gradient from lighter upper third to medium gray bottom, soft understated center lightening. Sparse repeating Lumen icons in a low-contrast darker gray, about 5–8% darker than the surrounding base: one main row of 4 small icons, with a few faint smaller offset ones. Icons should be subtle surface markings, never embossed holes.
Style: clean hand-painted stylized game texture, darkened narrow perimeter edges, a few interrupted pale edge glints and tiny restrained chipped paint shapes near perimeter, 2–3 delicate scuffs. Keep 90% of surface clean and smooth, no grunge, no noise, no metallic photo reflections, no thick black outlines, no screws, no panel seams. Mostly neutral-gray, not noticeably blue.
This will be mapped onto each wide side of a three-layer rounded crate and baked into a UV atlas. Flat texture only.
